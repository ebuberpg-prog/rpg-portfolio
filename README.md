# rpg-portfolio

EbubeRPG portfolio foundation built with Next.js, TypeScript, Tailwind CSS, shadcn/ui, and Framer Motion.

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` checks the production build.
- `npm run lint` runs linting.

## Content

Portfolio content lives in `src/data`. Project media can be added to `public/projects` once final assets are ready.
